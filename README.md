# ♡ PINKÉ BEAUTY

A feminine, elegant, and modern online makeup store.

## About

PINKÉ BEAUTY is a beauty e-commerce website concept
built using HTML, CSS, and JavaScript.

The design features a soft pink aesthetic,
elegant typography, and playful animations.

## Features

- Responsive website
- Product catalog
- Product categories
- Product search
- Shopping cart
- Add and remove products
- Quantity management
- LocalStorage cart persistence
- Mobile navigation
- Animated UI elements
- Newsletter demo

## Technologies

- HTML5
- CSS3
- JavaScript
- Lucide Icons
- Google Fonts

## How to Run

1. Download or clone this repository.
2. Open index.html in your browser.
3. Explore the store.

## GitHub Pages Deployment

1. Upload all project files to GitHub.
2. Open repository Settings.
3. Select Pages.
4. Choose Deploy from a branch.
5. Select the main branch.
6. Select the root folder.
7. Click Save.

Your website will be published using GitHub Pages.

## Important Notes

This project is a front-end demonstration.

The shopping cart uses browser LocalStorage.
Real payments, customer accounts, inventory,
and order management require a backend integration.
